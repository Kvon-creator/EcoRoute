# EcoRoute branding

Based on the Gemini logo sheet supplied by Kvon. Transparent PNG assets were prepared with OpenAI image editing.

The header uses the full-resolution alpha mask from ecoroute-light.png using a CSS image mask. Its color inherits the active app foreground (dark green in light mode, white in dark mode), including theme changes without a rerun. The browser scales the original PNG directly; no low-resolution image is generated for the header. The PNG is a raster source, not vector artwork.

ecoroute-dark.png is an earlier white asset, retained but no longer displayed. ecoroute-icon.png is the browser tab icon. Commit these small files with the app.
